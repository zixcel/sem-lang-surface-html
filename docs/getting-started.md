# Using @hathq/sem-lang-surface-html

Extract structural evidence from HTML without executing the page.

## Before you start

This parser does not run scripts, load a browser page or assign semantic meaning.

## First steps

Make the exact declared dependency artifacts available before installation. Local archives are excluded from Git; registry publication remains pending.

Run from the repository root:

```sh
npm install
npm run test
```

## How to assess the result

- Parse an inert HTML syntax tree.
- Produce bounded source-linked structural evidence.

A passing source-level check establishes only what that check observes. Keep missing configuration, unavailable services and unverified deployment paths visible.
